# Snow Client

Launcher oficial de **SnowMC Network** · [tienda.snowmc.us](https://tienda.snowmc.us) · [Discord](https://discord.gg/snowmc)

## Descargar

[**Descargar Snow Client para Windows**](https://github.com/santiivlog/snow-client-release/releases/latest/download/SnowClient-Setup.exe)

Ejecuta `SnowClient-Setup.exe` y sigue los pasos. No necesita permisos de administrador. El launcher se actualiza solo cuando sale una versión nueva.

> Windows puede mostrar "Windows protegió tu PC" la primera vez: pulsa **Más información → Ejecutar de todas formas**.
